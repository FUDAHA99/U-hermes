FAQ

常见问题

需要付费吗？
U-Hermes 完全免费开源（MIT 协议）。你只需要一个 AI 模型的 API 密钥——国内模型（如 DeepSeek）按量计费，日常使用一个月通常只要几块钱。
API 密钥去哪里申请？
配置页里每个模型都有申请入口提示。以 DeepSeek 为例：打开 platform.deepseek.com → 注册 → 充值几块钱 → 创建 API Key → 粘贴到配置页，点"测试连接"验证后保存即可。
发消息 AI 不回复怎么办？
运行 Windows-Menu.bat 选"一键诊断"，它会自动检查配置、网络和 API 状态，用人话告诉你问题和解决办法。最常见原因是 API 密钥过期或余额不足。
换一台电脑还能用吗？
可以。U 盘插到新电脑直接运行启动脚本，程序会自动修复路径。配置、记忆、对话记录都在 U 盘里跟着走。运行期间会在这台电脑的 %USERPROFILE%\.hermes\ 放一份配置副本（config.yaml 和 .env，里面有你的 API 密钥）供引擎读取。按 Ctrl+C 后在「终止批处理操作吗」处选 N，会删掉这两个文件（选 Y 是把脚本直接掐掉，清理就执行不到了）；下次在这台电脑上启动也会先清理上一次的残留，直接点窗口 X 关掉同理。随时可以用 Windows-Menu.bat 的 [8] 清理本机残留 补上。如果那台电脑原本装过 Hermes，它自己的配置会被先移开、退出时还原——那个文件夹里属于它的其它文件我们不会碰。
Windows 提示"已保护你的电脑"？
这是 Windows 对未签名脚本的默认提示。点"更多信息"→"仍要运行"即可。项目完全开源，代码可在 GitHub 查验。
如何更新到新版本？
小更新：运行 Windows-Menu.bat 选"更新"。大版本：先关掉 U-Hermes，把新压缩包直接解压到原目录、选"替换目标中的文件"即可——配置、密钥、聊天记录都在 data 里，压缩包不会覆盖它们。工作区在安装目录外面，同样不受影响。
