常见问题

需要付费吗？
U-Hermes 本身完全免费开源（MIT 协议）。你只需要一个 AI 模型的 API 密钥——国内模型（如 DeepSeek）按量计费，日常使用一个月通常只要几块钱。
API 密钥去哪里申请？
配置页里每个模型都有申请入口提示。以 DeepSeek 为例：打开 platform.deepseek.com → 注册 → 充值几块钱 → 创建 API Key → 复制到 U-Hermes 配置页，点"测试连接"验证后保存即可。
发消息 AI 不回复怎么办？
运行 Windows-Menu.bat 选择"一键诊断"，它会自动检查配置、网络和 API 状态，并用人话告诉你问题和解决办法。最常见的原因是 API 密钥过期或余额不足。
换一台电脑还能用吗？
可以。把 U 盘插到新电脑上直接运行启动脚本即可，程序会自动修复路径。你的配置、记忆和对话记录都在 U 盘里跟着走。
Windows 提示"已保护你的电脑"？
这是 Windows 对未签名脚本的默认提示。点"更多信息"→"仍要运行"即可。项目完全开源，代码可在 GitHub 查验。
如何更新到新版本？
小更新：运行 Windows-Menu.bat 选择"更新"。大版本：下载新的压缩包解压，把旧目录里的 data 文件夹复制过去，配置和记忆就都保留了。
