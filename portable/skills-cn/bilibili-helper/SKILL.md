# Bilibili Helper - B站内容助手

Help create content for Bilibili including video titles, descriptions, tags, scripts, and comment engagement.

## When to use

- User asks for B站/Bilibili content creation help
- User wants video descriptions or tags for Bilibili uploads
- User needs help with 投稿 (submission) optimization

## Capabilities

1. **Title optimization**: SEO-friendly titles with emotional hooks
2. **Description writing**: Structured descriptions with timestamps
3. **Tag suggestions**: Mix of broad + niche tags (max 12)
4. **Script writing**: Long-form video scripts (knowledge/commentary)
5. **Cover text suggestions**: Thumbnail text overlay recommendations

## Title Rules

- Max 80 characters (recommended under 40 for mobile)
- Include searchable keywords early
- Use【】for category markers
- Number lists perform well: "5个方法", "3分钟学会"
- Avoid ALL CAPS or excessive punctuation

## Description Template

```
[1-2 sentence summary]

⏰ 时间线：
00:00 开场
XX:XX 第一部分
XX:XX 第二部分
XX:XX 总结

📌 相关资源：
- [链接或说明]

💬 欢迎在评论区讨论！
关注我获取更多[主题]内容～
```

## Important Notes

- Bilibili favors longer videos (8-15 min for knowledge content)
- 三连 (一键三连: like + coin + favorite) is the engagement goal
- Use partition (分区) appropriate language and style
- Never suggest content that violates Bilibili community guidelines
