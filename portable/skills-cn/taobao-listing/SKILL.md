# 淘宝/电商商品文案

为淘宝、京东、拼多多等电商平台生成高转化率的商品文案，包括标题关键词优化、五点描述、详情页文案和主图文案。

## 触发词

`淘宝` | `商品描述` | `详情页` | `电商文案` | `拼多多` | `京东`

## 商品类型

### 服装类
- **标题重点**: 季节+风格+材质+场景+人群
- **卖点顺序**: 面料→版型→设计细节→穿搭场景→尺码建议
- **详情页逻辑**: 模特图→细节图→面料说明→尺码表→搭配建议
- **关键词库**: 显瘦、百搭、通勤、休闲、新款、设计感、高级感

### 数码类
- **标题重点**: 品牌+型号+核心参数+使用场景
- **卖点顺序**: 核心性能→对比优势→使用场景→售后保障→配件清单
- **详情页逻辑**: 产品图→核心参数→功能演示→场景应用→配件说明
- **关键词库**: 旗舰、性能、续航、轻薄、高清、快充、智能

### 食品类
- **标题重点**: 品牌+品类+规格+口味+产地
- **卖点顺序**: 原料/产地→制作工艺→口感描述→食用场景→保质期
- **详情页逻辑**: 产品图→原料展示→工艺说明→口感描述→食用建议
- **关键词库**: 新鲜、手工、零添加、地道、独立包装、代餐、解馋

### 家居类
- **标题重点**: 品类+材质+尺寸+风格+使用场景
- **卖点顺序**: 材质工艺→尺寸规格→设计亮点→使用场景→安装/保养
- **详情页逻辑**: 场景图→产品图→材质说明→尺寸图→安装说明
- **关键词库**: 简约、北欧、实木、收纳、多功能、环保、静音

## 商品标题规范

### 淘宝标题（60字符以内）

**核心原则**: 关键词堆叠，每个字都有搜索价值

**标题公式**:
```
[品牌词] + [核心品类词] + [属性词1] + [属性词2] + [场景词] + [人群词] + [促销词]
```

**标题示例**:
```
【服装】春秋新款女装法式复古碎花连衣裙收腰显瘦气质通勤长袖中长裙
【数码】2024新款蓝牙耳机真无线降噪运动跑步长续航高音质半入耳式
【食品】云南特产正宗鲜花饼玫瑰花味酥皮糕点手工现烤零食礼盒装
【家居】实木床头柜简约现代卧室收纳柜北欧风小型迷你储物柜原木色
```

### 标题关键词挖掘方法

1. **搜索下拉词**: 在淘宝搜索框输入品类词，看联想推荐
2. **生意参谋**: 查看热搜关键词和竞品标题
3. **竞品分析**: 参考销量前10的竞品标题用词
4. **属性组合**: 颜色+材质+风格+场景+季节+人群

### 标题禁忌
- 不堆砌无关关键词（会被降权）
- 不使用极限词："最好""第一""100%"
- 不抄袭竞品标题（平台会判定重复）
- 不用特殊符号分隔关键词

## 五点描述（卖点提炼）

五点描述即商品主要卖点的结构化展示：

```
✅ 卖点一：[核心优势]（解决什么问题）
✅ 卖点二：[材质/工艺]（为什么好）
✅ 卖点三：[使用场景]（什么时候用）
✅ 卖点四：[差异化]（和别人有何不同）
✅ 卖点五：[售后保障]（让人放心购买）
```

### 五点描述示例（蓝牙耳机）
```
✅ 48dB深度降噪 — 地铁公交也能沉浸听歌，告别外界干扰
✅ 36小时超长续航 — 充一次用一周，通勤出差无焦虑
✅ 舒适半入耳设计 — 单耳仅3.8g，久戴不累不闷热
✅ 蓝牙5.3秒连 — 开盖即连，游戏延迟低至48ms
✅ IPX5防水防汗 — 运动跑步随心用，品质保障365天
```

## 详情页文案结构

```
【首屏】产品主视觉 + 一句话核心卖点
        例："36小时续航，你的全天候音乐伙伴"

【痛点引入】
        目标用户遇到什么问题？
        例："通勤路上噪音太大？耳机总是没电？"

【解决方案】
        我们的产品如何解决这些问题
        展示核心功能（配合产品图/场景图）

【功能详解】（3-5个核心功能，每个配一屏）
        功能名称 + 数据指标 + 使用场景

【材质/工艺】
        用料说明、制作工艺、品质保障

【使用场景】
        展示多个使用场景，让用户代入

【规格参数】
        详细的产品参数表

【用户评价/认证】
        好评截图、质检报告、品牌资质

【售后保障】
        退换政策、质保时间、客服承诺

【尺码/规格选择指南】（如适用）
        帮用户做决定，减少咨询
```

## 主图文案

### 主图要求
- 淘宝：5张主图（800×800px起），第一张为白底/场景图
- 京东：建议白底图为主
- 拼多多：注重性价比展示

### 主图文案公式
```
图1（封面）：产品主图 + 品牌logo（干净简洁）
图2（核心卖点）：最大卖点 + 数据支撑
图3（功能展示）：功能细节 + 使用场景
图4（对比/规格）：尺寸/颜色/规格展示
图5（促销/保障）：活动价格/赠品/售后承诺
```

### 主图文案示例
```
图2文案："48dB主动降噪 | 36h超长续航 | 3.8g轻若无物"
图3文案："通勤·运动·办公·游戏 四大场景全覆盖"
图5文案："下单即送收纳盒 | 365天只换不修 | 顺丰包邮"
```

## 电商文案禁忌

1. **广告法禁用词**: 最、第一、顶级、极致、绝对等极限词
2. **虚假宣传**: 无法验证的功效宣称
3. **医疗暗示**: 食品/保健品不能暗示治疗功效
4. **价格欺骗**: "原价"必须有真实交易记录
5. **图文不符**: 详情页展示与实物不一致

## 注意事项

- 所有文案遵循《广告法》和平台规则
- 不使用竞品品牌名作为标题关键词（违规）
- 详情页图片中的文案也要避免违禁词
- 不同平台的文案风格需要适配调整
- 定期更新关键词（跟随搜索趋势变化）
