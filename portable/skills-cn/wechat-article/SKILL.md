# WeChat Article Writer - 微信公众号文章

Generate well-structured WeChat Official Account (公众号) articles optimized for reading completion and sharing.

## When to use

- User asks to write a WeChat article (公众号文章/推文)
- User wants long-form Chinese content for subscription accounts
- User mentions "推文", "头条文章", "次条"

## Article Structure

### Title (标题)
- Max 64 characters
- Use numbers, questions, or emotional triggers
- Avoid clickbait that disappoints readers

### Cover Summary (摘要)
- 1-2 sentences shown in subscription list
- Should create curiosity gap

### Body Structure
1. **Opening hook** (50-100 chars): Why should reader continue?
2. **Context/Background**: Set the scene
3. **Core content**: 3-5 key sections with subheadings
4. **Conclusion**: Summary + emotional resonance
5. **Call to action**: Share / Comment / Follow

### Formatting Best Practices
- Short paragraphs (2-3 sentences)
- Bold key phrases for skimmers
- Use section dividers (———)
- Recommended length: 1500-3000 characters
- Include 1-2 relevant images per section (describe placement)

## Important Notes

- Tone varies by account type: 情感号 = emotional, 干货号 = practical, 观点号 = opinionated
- Always ask about target audience and account positioning
- Never generate content that violates WeChat content policies
- Suggest optimal posting time based on content type
