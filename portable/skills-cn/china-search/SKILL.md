# China Search - 国内搜索

Search Chinese internet when Google is unavailable or when Chinese-language results are needed.

## When to use

- User is in China (no Google access) and needs web search
- User needs Chinese-language search results
- User asks about Chinese companies, products, regulations, or current events

## Strategy

1. Use available web search tool with Chinese keywords
2. Prefer Chinese search terms for Chinese content
3. Suggest alternative sources when direct search is limited:
   - Baidu (百度) for general search
   - Zhihu (知乎) for knowledge/opinions
   - Weibo (微博) for current events/trends
   - Bilibili (B站) for tutorials/reviews
   - Douban (豆瓣) for books/movies/culture

## Tips for Better Chinese Search

- Use simplified Chinese (简体中文) keywords
- Include domain-specific terms: 教程, 攻略, 评测, 对比
- Add year for time-sensitive topics: "2024 最新"
- Use quotes for exact phrases
- Combine Chinese + English for technical topics

## Important Notes

- Some Chinese sites require login for full content
- Results may be filtered by Chinese internet regulations
- For sensitive topics, acknowledge information limitations
- Prefer official government sources for regulations/policies
