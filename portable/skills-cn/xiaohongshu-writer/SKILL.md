# 小红书文案生成器

生成适合小红书平台风格的种草笔记和内容文案。

## 触发条件

当用户提到：小红书、种草、笔记、好物推荐、探店、打卡、小红书文案、RED note。

## 写作规范

### 标题
- emoji 开头，15-25 字
- 包含数字或对比（"5个"、"从XX到XX"）
- 可用竖线 | 分隔关键词

### 正文
- 每段 emoji 开头，2-3 句
- 总字数 300-800 字
- 口语化、有温度感，像朋友推荐
- 适当使用网络用语（yyds、绝绝子等，不过度）

### 标签
- 5-10 个 # 话题标签
- 前 3 个热门大标签（#好物推荐 #生活方式）
- 后面精准小标签（#北京探店 #平价护肤）

## 内容类型

### 种草笔记
```
[emoji] 标题（产品名 + 核心卖点）

[emoji] 使用场景/痛点引入
[emoji] 产品介绍（外观/质地/功能）
[emoji] 使用感受（真实体验）
[emoji] 优缺点总结
[emoji] 推荐理由

#标签1 #标签2 ...
```

### 探店打卡
```
[emoji] 标题（店名 + 地点 + 亮点）

📍 地址：XXX
💰 人均：XX元
⏰ 营业时间：XX

[emoji] 环境描述
[emoji] 推荐菜品/产品
[emoji] 真实评价
[emoji] 拍照tips

#标签1 #标签2 ...
```

### 好物合集
```
[emoji] 标题（数字 + 品类 + 人群）

1️⃣ [产品名] — 一句话推荐理由
2️⃣ [产品名] — 一句话推荐理由
...

[emoji] 使用心得总结

#标签1 #标签2 ...
```

## 注意事项

1. 全程使用简体中文
2. 避免硬广感，保持真实感
3. 主动建议封面图构图和配图方案
4. 适配小红书算法：标题含关键词、正文自然融入搜索词
5. 不编造产品功效，不涉及医疗建议
