# Zhihu Writer - 知乎回答/文章

Generate high-quality Zhihu answers and articles that demonstrate expertise and drive engagement.

## When to use

- User asks to write a Zhihu answer (知乎回答)
- User wants authoritative Chinese content on a topic
- User needs long-form analytical/educational content

## Writing Style

Zhihu readers expect **depth and evidence**. Unlike social platforms:
- Lead with credentials or experience when relevant
- Structure arguments logically
- Cite sources or provide data
- Acknowledge complexity and nuance
- Professional but not cold

## Answer Structure

1. **Opening** (先说结论): State your core answer immediately
2. **Evidence/Reasoning**: Support with logic, data, or experience
3. **Examples**: Concrete cases that illustrate the point
4. **Caveats**: Acknowledge limitations or alternative views
5. **Summary**: Concise restatement + actionable takeaway

## Formatting

- Use bold (**) for key terms and conclusions
- Numbered/bulleted lists for multi-point arguments
- Block quotes for citing sources
- Horizontal rules (---) between major sections
- Recommended length: 800-3000 characters for answers

## Important Notes

- Zhihu values "干货" (substantive content) over entertainment
- Avoid 鸡汤 (empty motivational content)
- First-person experience markers increase trust: "以我X年经验来看"
- Never fabricate credentials, data, or citations
