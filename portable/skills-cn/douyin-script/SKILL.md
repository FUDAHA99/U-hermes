# 抖音短视频脚本生成器

生成高完播率的抖音短视频脚本，包含画面描述、台词和发布建议。

## 触发条件

当用户提到：抖音、短视频、口播、带货脚本、知识分享、视频文案、TikTok。

## 脚本结构（黄金公式）

### 1. 开头 Hook（0-3秒）— 黄金3秒
最关键，必须让观众停下来。

Hook 类型：
- **冲突型**：「所有人都在做错这件事」
- **数字型**：「月入3万的副业，90%的人不知道」
- **提问型**：「为什么你的XXX总是失败？」
- **反转型**：「用了这个方法之后...」
- **社交证明**：「100万人已经在用的技巧」

### 2. 正文（3-45秒）— 价值输出
- 拆成 2-4 个要点
- 每个要点 10-15 秒
- 过渡词：「第一/第二/最后」「但是」「关键是」
- 包含具体数字和案例

### 3. 结尾（最后3-5秒）— 引导互动
- 行动号召：「关注我」/「评论区告诉我」/「点赞收藏」
- 系列预告：「下期教你更绝的」
- 金句收尾

```
【标题】含话题标签的发布标题

【时长】约XX秒
【类型】口播/剧情/教程/带货

【开头 hook — 0~3秒】
画面：...
台词：「...」

【正文 — 3~45秒】
画面：...
台词：「...」

【结尾 — 最后5秒】
画面：...
台词：「...」

【发布建议】
- 最佳时间：
- 话题标签：#xxx #xxx
- 封面建议：
- BGM建议：
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 时长 | 30-60秒 | 平台最佳完播区间 |
| 语速 | ~3字/秒 | 口播内容的节奏 |
| 风格 | 根据主题 | 知识类略正式，生活类轻松 |

## 注意事项

1. 全程简体中文
2. 画面描述和台词同步输出
3. 不建议违反平台规范的内容
4. 带货脚本需标注产品卖点和优惠信息
5. 主动建议封面文字和 BGM 风格
