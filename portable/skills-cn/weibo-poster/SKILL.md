# Weibo Poster - 微博文案生成

Generate engaging Weibo posts optimized for sharing and trending topic participation.

## When to use

- User asks to write a Weibo post (微博/博文)
- User wants to participate in trending topics (热搜)
- User needs microblog content in Chinese

## Rules

- Max 140 characters for optimal engagement (can be longer but shorter performs better)
- Include 1-2 topic tags: #话题# format
- Use @ mentions when relevant
- Emoji usage: moderate (less than Xiaohongshu)
- Tone: more direct and opinionated than other platforms
- For long-form: use Weibo's 头条文章 format

## Post Types

1. **Opinion/Commentary** (观点类): Bold statement + reasoning
2. **Information sharing** (分享类): Key facts + source attribution  
3. **Interaction** (互动类): Question/poll + engagement hook
4. **Promotion** (推广类): Value-first + soft CTA

## Important Notes

- Weibo has strict content moderation - avoid sensitive political topics
- Hashtag format is #内容# (with # on both sides)
- Super topics (超话) use different format for community posts
- Consider Weibo's algorithm: engagement in first 30 minutes is critical
