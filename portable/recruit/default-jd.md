# 新媒体运营（小红书 / 抖音方向）

> 青禾智选科技有限公司，虚构演示岗位。实际使用前由 HR 确认。

- 工作地点：杭州余杭，未来科技城 XX 大厦 8 楼（虚构地址）。
- 薪资：月薪 8K–13K，13 薪；招聘 2 人。
- 工作时间：早 9:30 – 晚 6:30，午休 1.5 小时，双休；每月可申请 2 天居家办公。

## 岗位职责

1. 负责品牌小红书、抖音账号的内容策划与日常发布，每月产出笔记 / 短视频不少于 40 条。
2. 跟进达人合作与投放，整理投放数据，持续优化 ROI。
3. 每周做数据复盘，分析爆款内容与竞品动态。
4. 配合大促活动（618、双 11）做内容和直播准备。

## 任职要求

1. 有新媒体运营经验，1 年以上经验优先；也欢迎有相关实践成果的优秀应届生。
2. 熟悉小红书、抖音平台规则和流量逻辑，有涨粉或爆款案例。
3. 会用剪映、Canva 等工具，能理解基础运营数据。
4. 沟通顺畅、执行力强，能说明个人在内容项目中的具体贡献。

## 加分项

家居 / 生活方式类账号经验，达人合作或投放优化经验。

## 福利

五险一金（公积金按 12% 缴纳）、带薪年假、免费午餐、零食下午茶、年度体检等；具体以公司资料为准。
